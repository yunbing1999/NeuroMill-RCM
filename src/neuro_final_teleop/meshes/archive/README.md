# Archived source meshes

These original CAD-export meshes are retained for reference and future remodeling:

- `Mount_Milling_xArm.stl`: original holder mesh.
- `Model_Milling.stl`: simplified tool mesh, not a full EMAX2PLUS model.
- `Mount_and_Milling.stl`: combined holder and simplified tool mesh.

No active source code or launch file references these STL files. They retain their
original coordinates and scale and are not installed by setup.py.

Current RViz geometry uses `../milling/mount_sensor_frame_m.stl` and the continuous
drill mesh generated by `drill_mesh.py`, with `../milling/drill_continuous_m.stl`
as the default static mesh. Do not substitute archived meshes without checking
units and transforms.
